# Apothicaire logo

A hand-drawn mortar and pestle inside a wreath of leafy branches, ochre on white. The artwork was drawn by hand by Amina and commissioned by the repository owner; this directory holds the vectorised version, traced from the original PNG as drawn (no redesign).

Credit: original drawing by Amina.

| file | use |
|---|---|
| `apothicaire-logo.svg` | original ochre (`#A27A0E`) on transparent, for light backgrounds |
| `apothicaire-logo-dark.svg` | lighter gold (`#E3B94F`) on transparent, for dark backgrounds and night mode |
| `apothicaire-logo-black.svg` | near-black (`#111`) on transparent |
| `apothicaire-logo-white.svg` | white on transparent |
| `apothicaire-logo-mono.svg` | `currentColor` on transparent: follows the text colour, so it switches with the light or dark theme without swapping files |
| `apothicaire-logo-small*.svg` | same five variants, simplified for small sizes (about 16 to 64 px): the wreath and the strokes of the mortar are thickened, the tiny highlights on the leaves and the inner rim lines are filled |

All files share the same square `viewBox` (`0 0 1000 1000`). Use the `small` set below roughly 64 px, the full set above.
